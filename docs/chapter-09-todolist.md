# 第九章练习清单

配套说明见 [chapter-09-handwrite-guide.md](./chapter-09-handwrite-guide.md)。按教程 9-01～9-14 顺序练习；以下业务项没有提前完成。

## 页面准备

- [x] 文章排名：动态列复选框、初始全列表格、操作按钮和分页的 Tailwind 模板。
- [x] 文章详情：标题、作者/时间、编辑入口和正文展示容器。
- [x] 静态文案接入中英文，复选框使用稳定字段值。
- [x] 表面、边框、文字和拖拽占位样式接入现有主题变量。

## 9-02：列表与分页

- [ ] 自己创建文章列表 API，明确参数和响应字段。
- [ ] 请求结果赋给 `tableData` 和 `total`，处理加载和失败。
- [ ] 实现 `handleSizeChange`，更新页大小并处理当前页码。
- [ ] 实现 `handleCurrentChange`，更新页码并重新请求。
- [ ] 结合现有 keep-alive，确定首次进入和重新激活时的加载策略。

## 9-03：相对时间与语言

- [ ] 自己加载 Day.js 相对时间插件和所需 locale。
- [ ] 处理时间戳/数字字符串，完成时间格式化方法。
- [ ] 接到列表和详情的发布时间位置。
- [ ] 切换中英文后，相对时间和需要重新请求的业务内容正确更新。

## 9-04～9-07：动态列

- [ ] 把动态列状态自行拆到教程对应的 `dynamic/` 模块。
- [ ] 区分全部列、选中值和实际显示列。
- [ ] 让 `tableColumns` 根据 `selectDynamicLabel` 更新。
- [ ] 保持列顺序与原始列描述一致。
- [ ] 验证取消全部和重新勾选。
- [ ] 按稳定的 `prop` 匹配，语言切换不丢失选列。

## 9-08～9-11：拖拽排序

- [ ] 自己引入 Sortable，使用 `tableRef` 定位表格 tbody。
- [ ] 保存实例，配置 `ghostClass: 'sortable-ghost'`，确定初始化和清理时机。
- [ ] 实现拖拽结束回调，判断源索引和目标索引是否有效、是否相同。
- [ ] 自己编写排序 API，并根据真实排名完成持久化。
- [ ] 同步本地表格和服务端顺序；处理请求失败。
- [ ] 验证翻页和缓存激活不会产生重复实例。

## 9-12：删除

- [ ] 实现删除确认，文案使用国际化。
- [ ] 自己编写删除 API 并传文章 `_id`。
- [ ] 成功提示后刷新列表，考虑当前页最后一条数据。
- [ ] 正确处理取消和失败。

## 9-13：详情

- [ ] 实现 `onShowClick`，跳转 `/article/:id`。
- [ ] 从路由读取 id，自己请求详情并赋给 `detail`。
- [ ] 正文绑定和相对时间正确，内容来源与 HTML 展示边界明确。
- [ ] 缓存激活和语言切换后的业务数据符合预期。
- [ ] 编辑入口留待第十章实现。

## 9-14：最终自查

- [ ] 中英文界面及相对时间均正确。
- [ ] 浅色、暗色以及亮/深主色下的表格和拖拽占位均可读。
- [ ] 窄屏无页面级横向溢出，区域内滚动正常。
- [ ] 能解释选列、排序、删除、详情这四条数据流。
