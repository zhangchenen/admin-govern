## HTML / SCSS 到 Tailwind 的对应关系

| 教程的结构或样式                            | 本项目的写法                                                                | 原因                                           |
| ------------------------------------------- | --------------------------------------------------------------------------- | ---------------------------------------------- |
| 顶部卡片 `margin-bottom: 20px`              | 外层 `flex flex-col gap-5`                                                  | 维持 20px 区块间距                             |
| `.dynamic-box` 的 flex 和标题间距           | `flex flex-col gap-3 sm:flex-row sm:items-start sm:gap-5`                   | 窄屏换行，英文列名也能容纳                     |
| 标题 `14px/bold`                            | `text-sm leading-8 font-semibold`                                           | 与复选框行高对齐                               |
| 分页 `margin-top: 20px; text-align: center` | `mt-5`、内部 `flex justify-center`                                          | 保留教程居中布局；窄屏在区域内横向滚动         |
| 表格行 `cursor: pointer`                    | `[&_.el-table__row]:cursor-pointer`                                         | 样式已准备，拖拽本身仍未实现                   |
| `.sortable-ghost` 透明度及固定深蓝背景      | `[&_.sortable-ghost]:opacity-60`、目标单元格 `bg-primary! text-on-primary!` | 拖拽占位随主题色变化，文字使用项目计算的对比色 |
| 详情标题 `22px`、居中、上下 `12px`          | `text-[22px] text-center py-3`                                              | 保留教程尺寸                                   |
| 元数据 `padding: 26px 0`、间距 `20px`       | `py-[26px] flex flex-wrap gap-x-5 gap-y-3`                                  | 替代浮动，窄屏可换行                           |
| 编辑按钮 `float: right`                     | `ml-auto! shrink-0`                                                         | 在弹性布局中靠右                               |
| 正文 `14px`、上下 `20px`、顶部边框          | `text-sm leading-7 py-5 border-t border-border`                             | 保留结构并适应换肤                             |

详情正文来自教程的 `v-html` 容器。Tailwind Preflight 会清除标题、段落和列表的浏览器默认样式，所以容器用后代工具类补回基础排版；图片、代码块和表格增加区域内溢出处理。没有复制第十章的编辑器工具栏或编辑器主题。后续接入正文数据时，应按实际内容来源确定可信 HTML/清理边界；本次没有填入正文数据。

## 国际化与主题适配

### 界面文字和列状态

所有界面文案在模板里调用 `$t`，包括列名、按钮、空状态和作者/时间标签。Element Plus 分页文字继续复用项目 `App.vue` 的 `el-config-provider`。

教程用翻译后的 `label` 作为复选框值。本项目用 `ranking`、`title`、`author`、`publicDate`、`desc`、`action` 作为复选框值和 `key`，`labelKey` 仅存翻译键，显示时再翻译。这样切换语言不会改变复选框值，也不需要为了换语言清空用户选列。完成动态列逻辑时，继续按 `prop` 匹配，避免又改回按翻译文字匹配。

静态文字换语言已经接好。服务器返回的文章标题/内容、相对时间、删除确认与成功提示等业务国际化，由你在对应练习中完成。项目现有日期插件是 `$filter.dateFilter`，不是教程的 `$filters`，而且尚无 `relativeTime`；模板没有调用一个不存在的方法。

### 明暗模式与主题色

| 作用              | 使用的项目变量/工具类                                              |
| ----------------- | ------------------------------------------------------------------ |
| 页面/表面         | `bg-page`、`bg-surface`，分别来自 `--app-page`、`--app-surface`    |
| 正文/次要文字     | `text-foreground`、`text-muted`                                    |
| 边框              | `border-border`                                                    |
| 正文链接          | `text-[var(--app-primary-text)]`，使用明暗模式下计算后的强调文字色 |
| 拖拽占位背景/文字 | `bg-primary!`、`text-on-primary!`，不固定白字                      |
| 按钮/复选框       | 继续用 Element Plus 的 `type="primary"` 和现有全局主题变量         |
| 表格悬停          | `--app-primary-soft`                                               |

卡片和表格通过 Tailwind 的 CSS 自定义属性工具类，把 Element Plus 的局部颜色变量接到本项目的 `--app-*`。末尾的 `!` 用来避免组件库默认样式覆盖这些变量。暗色开关与主色选择仍走现有 theme store，无需给本章页面新增监听或直接写 DOM。

本项目 `src/style/index.scss` 还存在没有放入 CSS layer 的全局 `margin: 0; padding: 0` 重置，它会压过普通 Tailwind 间距工具类。实际组件在对应位置使用 `py-3!`、`mt-5!` 等带优先级的类；复选框/按钮间距、卡片圆角也按组件库样式加了必要的 `!`。上表列出的是布局含义，具体标记以源文件为准。本次只做本章局部适配，没有改动全局 reset。

本次没有引入固定蓝色、固定白色正文或独立的暗色开关，也没有修改全局主题算法。

## 完成逻辑后的自查

1. 中英文切换后，六个列名、按钮、空状态、分页及相对时间都随语言变化；用户选列仍保留。
2. 默认全列、取消任意列、取消全部、重新勾选时，实际列与选择一致，顺序稳定。
3. 浅色、暗色以及深色/亮色主色组合下，卡片、表格、悬停行和拖拽占位文字可读。
4. 窄窗口中复选框会换行，表格和分页在自身区域内滚动，详情图片和长代码不撑破页面。
5. 来回进入缓存页面时，不会重复创建 Sortable 实例；销毁/停用时按你的设计清理。
6. 请求失败、删除取消、同位置拖拽、拖拽失败都有明确处理；不要把失败当作成功。

当前只完成模板和样式准备。表格能显示空状态，不等于本章的业务已经完成；清单勾选以你亲手实现并验证后的结果为准。
