# 第六章个人中心：手写掌握标准

其余个人中心业务已接入。下面两项留作手写练习，完成后再把临时头像替换为 `PanThumb`，并让功能和章节页签显示接口数据。

## 1. PanThumb 头像组件

建议文件：`src/components/PanThumb/index.vue`

- 使用 `<script setup lang="ts">` 定义并约束 `image`、`width`、`height`、`zIndex`、`hoverable` 属性，并设置合理默认值。
- 用插槽承载头像翻转后展示的内容。
- 将头像图像和插槽层叠为圆形；尺寸由属性控制，不依赖固定像素尺寸。
- 仅在 `hoverable` 开启时添加翻转效果；动画围绕右侧偏上的位置旋转，图像保持居中裁切。
- 在个人中心介绍卡和作者介绍中使用该组件，并检查窄屏下两种尺寸都不溢出。

## 2. 功能和章节数据请求

API 包装和返回类型已在 `src/api/profile.ts` 提供：`getProfileFeatures()`、`getProfileChapters()`。

- 在个人中心页和 `Chapter.vue` 中分别维护有类型的列表状态与加载状态。
- 组件挂载后请求对应 API；成功时更新列表，失败时清空列表，`finally` 中结束加载。
- 加载时显示骨架屏；无数据时显示 Element Plus 空状态；成功时列表分别进入功能折叠面板、功能进度条和章节时间线。
- 请求失败由共享 `src/utils/request.ts` 拦截器提示，不要再重复弹出错误消息。
- 本练习不要求实现接口语言切换或语言变化后重新请求；界面静态文案继续使用项目现有 `$t` 字典。

## 完成标准

- 刷新个人中心后，功能进度和折叠详情来自 `/user/feature`，章节时间线来自 `/user/chapter`。
- 请求加载期间有明确反馈；空数组和请求失败都能显示空状态，不产生未处理的 Promise rejection。
- 中英文切换只更新页面静态文案；这两项练习不添加接口国际化逻辑。
